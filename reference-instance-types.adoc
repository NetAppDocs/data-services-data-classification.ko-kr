= 지원되는 NetApp Data Classification 인스턴스 유형
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp 데이터 분류 소프트웨어는 특정 운영 체제 요구 사항, RAM 요구 사항 및 소프트웨어 요구 사항을 충족하는 호스트에서 실행되어야 합니다. 클라우드에 데이터 분류를 배포할 경우, 모든 기능을 활용하려면 "large" 사양의 시스템을 사용하십시오.

다음 표에서 "default"로 표시된 시스템을 NetApp Data Classification을 설치하는 지역에서 사용할 수 없는 경우 표에 나열된 다음 인스턴스 유형이 배포됩니다.

[cols="20,30,25"]
|===
| 시스템 크기 | 명세서 | 인스턴스 유형 


| 특대 | 32개 CPU, 128GB RAM, 1TiB gp3 SSD | https://aws.amazon.com/ec2/instance-types/m6i/["m6i.8xlarge"^](기본) 


| 크기가 큰 | CPU 16개, 64GB RAM, 500GiB SSD | https://aws.amazon.com/ec2/instance-types/m6i/["m6i.4xlarge"^](기본값) m6a.4xlarge m5a.4xlarge m5.4xlarge m4.4xlarge 
|===
