= NetApp Data Classification 데이터 소스에서 수집된 메타데이터
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font

[role="lead"]
NetApp Data Classification은 데이터 소스와 시스템을 스캔하는 동안 메타데이터를 수집합니다. 대부분의 메타데이터를 사용할 수 있지만, 일부 속성은 모든 프로토콜에서 사용 가능한 것은 아닙니다.

[cols="15,25,25,25"]
|===
|  | *메타데이터* | *CIFS* | *NFS* 


.3+| *타임스탬프* | _생성 시간_ | 사용 가능 | 사용할 수 없음(Linux에서는 지원되지 않음) 


| 마지막 접속 시간 | 사용 가능 | 사용 가능 


| 최종 수정 시간 | 사용 가능 | 사용 가능 


.2+| *권한* | _열기 권한_ | "EVERYONE" 그룹이 파일에 액세스할 수 있는 경우 해당 파일은 "조직에 공개"로 간주됩니다. | "기타"가 파일에 액세스할 수 있는 경우 해당 파일은 "조직에 공개됨"으로 간주됩니다. 


| _사용자/그룹 액세스_ | 사용자 및 그룹 정보는 LDAP에서 가져옵니다. | 사용할 수 없음(NFS 사용자는 일반적으로 서버에서 로컬로 관리되므로 동일한 개인이 각 서버에서 다른 UID를 가질 수 있음) 
|===
[NOTE]
====
* 데이터 분류는 데이터베이스 데이터 소스에서 "마지막 액세스 시간"을 추출하지 않습니다.
* Windows 7 및 Windows 8과 같은 이전 버전의 Windows OS에서는 "마지막 액세스 시간" 속성 수집이 시스템 성능에 영향을 줄 수 있으므로 기본적으로 비활성화되어 있습니다. 이 속성이 수집되지 않으면 "마지막 액세스 시간"을 기반으로 하는 Data Classification 분석에 영향을 미칩니다. 필요한 경우 이러한 이전 버전의 Windows 시스템에서 마지막 액세스 시간 수집을 활성화할 수 있습니다.


====


== 마지막 액세스 시간

데이터 분류 기능이 파일 공유에서 데이터를 추출하면 운영 체제는 이를 액세스 이벤트로 간주하고 "마지막 액세스 시간"을 업데이트합니다.  스캔 후 데이터 분류 기능은 마지막 액세스 시간을 원래 타임스탬프로 되돌리려고 시도합니다.  데이터 분류 기능에 CIFS의 쓰기 속성 권한 또는 NFS의 쓰기 권한이 없는 경우 시스템은 마지막 액세스 시간을 원래 타임스탬프로 되돌릴 수 없습니다.

기본적으로 Data Classification은 원래 타임스탬프를 복원할 쓰기 권한이 없는 파일은 검사하지 않습니다. 데이터의 마지막 접근 시간이 원래 타임스탬프로 재설정되지 않아도 괜찮은 경우, 시스템 구성 페이지에서 *쓰기 권한 없이 검사* 옵션을 활성화하십시오.

image:screenshot_scan_missing_permissions.png["Data Classification이 마지막 액세스 시간을 원래 타임스탬프로 되돌릴 수 있는 올바른 권한이 없더라도 파일을 스캔하는 데 사용할 수 있는 스위치를 보여주는 스크린샷입니다."]

이 기능은 온프레미스 ONTAP 시스템, Cloud Volumes ONTAP, Azure NetApp Files, Amazon FSx for NetApp ONTAP 관리 및 타사 파일 공유에 적용할 수 있습니다.


NOTE: ONTAP 볼륨이 SnapLock으로 구성된 경우 읽기 전용 권한을 가지며 마지막 액세스 시간을 원래 타임스탬프로 되돌릴 수 없습니다.



=== 스캔 분석 이벤트

조사 페이지에는 _Scan Analysis Event_라는 필터가 있는데, 이 필터를 사용하면 Data Classification에서 마지막 액세스 시간을 되돌릴 수 없어서 분류되지 않은 파일 또는 Data Classification에서 마지막 액세스 시간을 되돌릴 수 없었음에도 불구하고 분류된 파일을 표시할 수 있습니다.

image:screenshot_scan_analysis_event_filter.png["쓰기 권한이 있는지 없는지에 따라 어떤 파일이 검사되었고 어떤 파일이 검사되지 않았는지 확인하는 필터의 스크린샷입니다."]

필터 선택은 다음과 같습니다.

* "분류되지 않음 -- 마지막 액세스 시간을 되돌릴 수 없음" - 이는 쓰기 권한이 없어 분류되지 않은 파일을 나타냅니다.
* "분류 및 최종 액세스 시간 업데이트됨" - 이 필터는 분류되었지만 NetApp Data Classification이 최종 액세스 시간을 원래 날짜로 재설정할 수 없었던 파일을 표시합니다. 이 필터는 *쓰기 권한 없이 스캔*이 활성화된 환경에서만 유효합니다.


필요한 경우, 이러한 결과를 보고서로 내보내 권한 문제로 인해 어떤 파일이 검사되고 어떤 파일이 검사되지 않는지 확인할 수 있습니다. link:task-investigate-data.html#download-your-report["데이터 조사 보고서에 대해 자세히 알아보세요"^].
