= VMware Open Virtual Appliance로 NetApp Data Classification 배포
:allow-uri-read: 
:no-hardbreaks: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Data Classification은 VMware Open Virtual Appliance(OVA)를 통한 배포를 지원하며, 온프레미스 VMware vSphere 환경에 Data Classification을 설치하고 실행할 수 있는 관리형 패키지를 제공합니다. OVA 배포 방식은 사전 검증된 NetApp 관리 환경을 제공하여 배포를 간소화합니다.

이 방법은 새로운 VMware 기반 배포에 권장됩니다.



[[prerequisites]]
== 필수 조건

Data Classification을 설치하기 위해 OVA 파일을 사용하기 전에 다음 사항을 확인해야 합니다.

* VMware vSphere 환경
* 어플라이언스에 할당된 고정 IPv4 주소
* 대상 네트워크에서 연결 가능한 DNS 서버
* 어플라이언스에 SSH 액세스가 활성화되었습니다.
* link:https://mysupport.netapp.com/site/user/registration["NetApp 지원 사이트 자격 증명"] 설치 프로그램을 다운로드하려면




[[deploy-the-ova-in-vmware-vsphere]]
== VMware vSphere에 OVA 구축

. link:https://mysupport.netapp.com/site/products/all/details/cloud-data-sense/downloads-tab/["NetApp 지원 사이트"^]에서 OVA 파일을 다운로드하십시오. 사용 환경에 적합한 OVA 어플라이언스를 선택하십시오.
+
|===
| OVA 어플라이언스 | 프로덕션 규모 | 파일 스캔 제한 


| `DataClassification-<version>-L.ova` | 표준 프로덕션 워크로드: CPU 16개, RAM 64GB, 디스크 500GB | 2억 5천만 개의 파일 


| `DataClassification-<version>-XL.ova` | 대규모 운영 워크로드: CPU 32개, RAM 128GB, 디스크 1TB | 5억 개의 파일 
|===
. vSphere 클라이언트를 실행합니다. 대상 클러스터 또는 호스트를 마우스 오른쪽 버튼으로 클릭한 다음 *Deploy OVF Template* > *Create VM from OVA*를 선택합니다.
. 1단계에서 다운로드한 OVA 파일을 업로드하십시오.
. *VM 이름*과 대상 데이터 센터, 호스트 또는 클러스터 및 데이터 저장소를 지정합니다.
. NetApp 최종 사용자 라이선스 계약에 동의하십시오.
. 템플릿을 사용자 지정합니다. 다음 정보를 제공해야 합니다.
+
** **호스트 이름** - 어플라이언스의 이름
** **IPv4 주소** - 관리 인터페이스의 고정 IPv4 주소
** **IPv4 서브넷 마스크** - 예: 255.255.255.0
** **IPv4 gateway 주소** - 기본 gateway
** **기본 DNS** - 필수 DNS 확인자
+
선택적으로 **보조 DNS**를 추가하고, 쉼표로 구분된 목록으로 **검색 도메인**(예: `corp.local,lab.local`) 및 **NTP 서버**를 추가합니다.



. 기본 Linux 사용자의 *관리 암호*를 설정하십시오.
+

NOTE: 이 비밀번호는 루트 액세스, SSH 액세스 및 시스템 관리에 사용됩니다. 비밀번호를 안전하게 보관하십시오.

. 요약을 검토하세요. 배포하려면 *Finish*를 선택하세요.
. 배포가 완료되면 VM을 켜십시오.




[[install-data-classification]]
== Data Classification 설치

. link:https://mysupport.netapp.com/site/products/all/details/cloud-data-sense/downloads-tab/["NetApp 지원 사이트"^]에서 Data Classification 소프트웨어를 다운로드하십시오.
+
*DATASENSE-INSTALLER-<version>.tar.gz*라는 이름의 파일을 선택하십시오.

. 설치 파일(Installer file)을 VM 호스트에 복사합니다. `tar -xzf DATASENSE-INSTALLER-<version>.tar.gz`.
. 호스트 컴퓨터에서 설치 파일의 압축을 해제하십시오.
. 콘솔에서 *거버넌스 > 분류*를 선택합니다.
. *Deploy Classification*을 선택합니다.
+
image:screenshot-deploy-classification.png["데이터 분류를 활성화하기 위한 버튼을 선택하는 스크린샷입니다."]

. 클라우드에서 준비한 인스턴스에 데이터 분류를 설치하는지, 아니면 사내에서 준비한 인스턴스에 데이터 분류를 설치하는지에 따라 적절한 *배포* 옵션을 선택하여 데이터 분류 설치를 시작합니다.
. _온프레미스에 데이터 분류 배포_ 대화 상자가 표시됩니다.  제공된 명령을 복사합니다(예: `sudo ./install.sh -a 12345 -c 27AG75 -t 2198qq` )을 텍스트 파일에 붙여넣어 나중에 사용할 수 있습니다.  그런 다음 *닫기*를 선택하여 대화 상자를 닫습니다.
. 관리자 사용자를 사용하여 SSH를 통해 OVA 어플라이언스에 연결합니다.
. 생성한 설치 명령을 실행하여 설치를 완료하고 시스템을 조직에 등록하십시오.
