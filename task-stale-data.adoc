= NetApp Data Classification 에서 오래된 데이터 정의를 사용자 지정합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp 데이터 분류는 오래된 데이터를 식별하여 비용 절감 기회를 찾고 거버넌스 위험을 해결할 수 있도록 지원합니다. 조직의 요구 사항에 맞게 오래된 데이터 정의를 사용자 지정하고 마지막 액세스 또는 마지막 수정 시간을 기준으로 오래된 데이터를 식별할 수 있습니다.

오래된 데이터는 마지막 접근 시점 또는 마지막 수정 시점을 기준으로 정의할 수 있습니다. 기간은 6개월에서 10년까지 선택할 수 있습니다.

기본적으로 데이터는 마지막 수정일로부터 3년이 지난 경우 오래된 것으로 간주됩니다.

.오래된 데이터를 정의합니다.
. 데이터 분류에서 **구성**을 선택합니다.
. Configuration 페이지에서 **Settings** 탭을 선택합니다.
. 오래된 데이터 정의 항목 아래에서 *편집*을 선택합니다.
. **파일 속성** 드롭다운 메뉴에서 *마지막 액세스* 또는 *마지막 수정* 시간을 기준으로 오래된 데이터를 정의할지 선택합니다.
. 오래된 데이터 정의에 사용할 기간을 선택하세요.
. **저장**을 선택하세요.
